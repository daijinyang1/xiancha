# 同类站点调研（2026-11-07）

> 全部链接都在 2026-11-07 当天实测可打开（HTTP 200）。分四类看：直接同类的没有，最接近的是「法律 AI + 合同审查」这一层，但他们服务企业、按年收费。

## 一、结论先说

1. **「大学生实习合同」这个细分，国内没有专门站点。** 有做合同审查的，全是 B 端（企业法务）、按年收费、不对学生。这是真空，也是你的机会。
2. **最接近的三家**：通义法睿（阿里）、幂律智能、法天使。它们都做「上传合同 → AI 指出风险条款」，但入口是律师和企业，不面向学生，也没有「坑型 + 法条 + 怎么改」的结构化输出。
3. **真正该抄的，是「查询类」产品的结构，不是法律产品的结构**：企查查、看准网、牛客查薪资——它们都是「一个搜索框 + 一个结构化结果页 + 一个榜单」，用户 3 秒知道该干什么。
4. **你现在缺的那个东西，它们都有：数据的「可查性」。** 你已经有 63 条规则，但只能在扫描页用；应该再加一个「规则词条页」——每条规则一个页面，能被搜到、能被收藏、能被引用。这是 SEO 的来源，也是评委看到「内容资产」的地方。

## 四之二、优校网（youxiaow.com）：值得学的形式，不值得学的做法

> 阳哥 2026-11-07 点名看的站：https://www.youxiaow.com/ 。结论是——**它的「页面组织形式」值得学，它的「内容生产方式」一个字都不能学。**

| 看什么 | 它怎么做 | 判断 |
|---|---|---|
| 一个实体一个页面 | 每所大学一个独立 URL（/daxue/guangdong/5873.html），页内分「学校介绍 / 开设专业 / 院校分数线 / 招生计划 / 院校评价」五个 Tab | **学**。这就是「一条规则一个页面」的同类做法 |
| 标题怎么写 | 用用户会搜的原话当标题（「XX 大学多少分能上」），不用「院校详情」这种内部术语 | **学**。你的词条页标题已经是「实习要交押金合法吗？」 |
| 内链 | 上下页切换 + 推荐阅读 + 相关问答，把用户留在站内 | **学**。你已经有上一条/下一条 + 案例与规则互链 |
| 内容来源 | 全站问答编号连续、发布日期全同一天（2026-10-09）、每篇浏览量都写「14953」——批量生成 + 造假数字 | **不学**。这类数字一眼假，被评委问一句就露 |
| 栏目范围 | 主站是院校，里面却混进汉语字典、成语、近义词、造句、古诗、康熙字典、五行字典、英语词典 | **不学**。泛内容冲淡定位，也让「你在做什么」说不清 |
| 数据出处 | 写「2023 年教育部数据、通过率 85%」，不给链接不给文号 | **不学**。你每条规则都必须能说出出处 |
| 免责声明 | 文末「本网站所收集内容来自网友分享仅供参考」当挡箭牌 | **不学**。免责是兜底，不是内容的替代品 |
| 技术细节 | /sitemap.xml 返回 404；robots.txt 把 GPTBot、ClaudeBot 等 AI 爬虫全禁了；页面模板 bug 写着「共收录大学院校大学 0 家」 | **不学**。你的 63 个词条页必须能被爬、能被索引 |

**一句话对比（可直接上 PPT）：**

> 优校网是「你不知道去哪找，我把全网抄一遍放在这」；先查是「你手上这份合同，我告诉你哪几句话不能签」。
> 前者比页面数量，后者比判断准度。

## 五、抄什么、不抄什么（落到你的站上）

### 该抄的三件

1. **首屏加一个即时查询框。** 现在首页是「点进去看」，改成「直接粘一句话，立刻告诉你有坑没坑」。这是从「工具站」变成「查询站」的关键一步，和你「先查」这个名字才对得上。
2. **63 条规则做成 63 个静态词条页（已落地）。** 每条规则一个独立文件 rules/R01.html 到 rules/R63.html：标题就是「实习要交押金合法吗？」这种学生真会问的话，正文是「判定 / 为什么有风险 / 依据哪条 / 怎么改 / 同坑型的真实案例」。这是 SEO 的入口，也是评委翻「内容资产」时唯一看得见的东西。生成器是 tools/gen_rule_pages.mjs，改了规则重跑一次即可，不手写。
3. **把数据量写在标题下面。** 学牛客：「已有 63 条规则、12 个真实案例、6 张证书，全部免费、不用登录」。比「专业」「智能」这类词有说服力一百倍。

### 不该抄的三件

1. **不做对话式聊天框。** 通义法睿那种「问它一句它答一句」，看起来先进，但你没有算力预算，答错了还要担责。你的定位是「查」，不是「聊」。
2. **不做企业查询那一套。** 企查查的路径是「查公司」，一旦涉足就是工商数据、征信、法律风险，你要买数据源，还要担责。你现在只查「表述」，不查「主体」，这是保护自己。
3. **不做付费墙和会员。** 上面所有 B 端产品都靠收费活着，你一旦收费，就得对企业负责，还可能踩「无资质提供法律服务」的线。保持免费 + 明确免责，是零预算下唯一安全的路。

它们都是「出了问题之后找人帮忙」，你是「出问题之前自己先查一遍」。这句话可以直接放进路演 P2 和 BP 第二章——因为它一句话说清了你不和谁抢生意。
