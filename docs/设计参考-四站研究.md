## 一、Framer（https://www.framer.com/）

标题「Framer: Free website builder and AI design agent」。

### 1. 首屏结构

单列居中式宣言 Hero，右侧跟上演示块，不做左右分栏图文：

- h1：「Framer is the pro website builder with a world-class design agent」——一句话把「是什么 + 关键差异化」说完，没有第二句解释。
- 副标题：`Build your website with agents and make it your own on a fully editable design canvas.` 补的是「差异化怎么落地」（可编辑画布）。
- 双 CTA：「Get started for free」（主）/「Install the MCP」（次）。次按钮不是「了解更多」，而是一个具体动作。
- 右侧 0:36 的视频/演示块，用长度标注（36 秒）而不是「点击观看」。
- 往下 section 顺序：Hero → Agents → Bento Features → Gallery → Stories → Community。

结构上的关键点：**首屏只有一个主行动**，社会证明和功能矩阵全部下沉到第二屏以后，不用首屏塞满。

### 2. 动效手法（时长 / 缓动）

动效参数不是写在 CSS 里，是内联 JSON（`<script type="framer/appear" id="__framer__appearAnimationsContent">`），说明它把入场动画当数据下发：

- 默认档（绝大多数元素）：`{"opacity": 0.001→1, "transition": {"type": "spring", "bounce": 0.2, "duration": 0.4}}` —— **400ms 的弹簧，bounce 0.2**。注意起始 opacity 是 `0.001` 不是 `0`，避免浏览器把 0 当作「未渲染」而跳过过渡。
- 位移档（少数重点块）：`y: 20→0`，`delay: 0.35`，`duration: 1`，`bounce: 0` —— **1000ms 位移入场 + 350ms 延迟**，用弹簧的 bounce=0 退化成纯缓出。
- 初始 style 直接写死 `will-change: transform; opacity: 0.001`，全站 274 处 `will-change`、4 处 `sticky`。
- 缓动另有一处 `cubic-bezier(.44, 0, .56, 1)`；`@keyframes` 只有 5 个（shimmer / ghostFlow / doubleSlow / danceSpark / blink-input），都是局部装饰，不用来驱动主体入场。
- 全站 `parallax` 关键词 **0 次** —— 这个量级的站点没有用视差。
- 支持 `prefers-reduced-motion: reduce`（渲染函数 `animateAppearEffects` 接收该参数）。

可抄的内核：**入场分两档，快的 400ms 只做淡入，慢的 1000ms 做位移**，靠 bounce 区分「轻」和「重」，而不是所有元素一个时长。

### 3. 配色与表面

- 底色 `rgb(0, 0, 0)` 纯黑（`html body` 直接给），不是深灰。
- 出现次数最多的颜色：`rgb(255,255,255)`×234、`rgb(20,20,20)`×138（卡片面）、`rgb(153,153,153)`×100（次要文字）、`rgba(255,255,255,0.1)`×72（分隔/描边）、`rgb(0,153,255)`×38（品牌蓝 `#09f`，只在交互态出现）。
- 表面处理：**暗底 + 1px 半透明白描边**，不是重投影。`border: 1px solid rgba(255,255,255,0.06)` 出现 24 次，是全站最主要的「面」的分界手段；另有 1px `#0099ff` 描边 12 次、1px `rgba(0,153,255,0.42)` 11 次（主按钮/激活态）。
- 阴影极少：`0 10px 20px #0000000d`×3、`0 2px 6px #0003`、`0 1px 2px #0000001a`，几乎不可见。
- 圆角直方图：8px×1591（压倒性主导）、15px×341、6px×139、4px×118、18px×84、20px×60、100px×60（药丸）。CTA 按钮 8px。

结论：**深色底上不用阴影做层级，用 6% 白描边做层级**。

### 4. 排版

- 字体族：标题 `GT Walsheim Medium`，正文/界面 `Inter` / `Inter Display`（CSS 里分别出现 135 次 / 126 次）+ `Inter Variable`。
- h1：`font-size: 54px`（基准）→ 42px（810–1199px）→ 36px（<810px），`font-weight: 500`，`letter-spacing: -.04em`，`line-height: 1em`。
- h2 preset：44px / 500 / `-.04em` / 1.1em。hero 副标题：18px / 400 / `-.2px` / 1.35em。
- 字号直方图：54 / 44 / 42 / 36 / 28 / 18 / 17 / 16 / 15 / 14 / 13 / 12 / 10px —— 档位密集在 14–18px，靠**字重和颜色**拉开层级，不靠字号暴涨。
- 行高直方图：1.6em×88、1em×72、1.4em×27、1.5em×24、1.35em×23、1.3em×21。**正文 1.6，标题 1.0–1.1**，中间档几乎没有，两级分化。

### 5. 对「先查」可抄的三条

1. **入场拆两档**：`.reveal` 现有 620ms 位移一档吃所有元素；再补一档 300–400ms 纯淡入（移位 0）给第二屏的卡片网格，避免每块都「从下往上顶」一样的节奏。
2. **起始 opacity 用 0.001 不用 0**：`.reveal` 现在是 `opacity: 0`，改成 `0.001` 可避免部分浏览器把元素判为不渲染、连 `will-change` 优化都拿不到；改动一行，收益是入场更稳。
3. **标题字距收紧到 -.02em ~ -.04em**：先查 h1 现在是 `tracking-[0.02em]`（正字距），中文大标题不需要正字距；中文标题可以留 0，但英文/数字标签类建议改负字距。

## 二、Webflow（https://webflow.com/）

标题「Webflow: The agentic web platform for modern businesses」。

### 1. 首屏结构

- h1：「Build for what's next」——四个词，几乎不承载信息，靠下面一句副标题兜住含义。
- 副标题：`Webflow gives every team the tools to build, manage, and grow a website that drives real revenue.`，class 里直接写 `u-max-40ch`（**行长限制在 40 字符**）。
- 双 CTA：「Get started」（主，`.btn`）/「Talk to Sales」（次）。
- 首屏紧接着就是横向 marquee 社会证明「What marketing teams love about webflow」，不等滚动：`data-marquee` 属性写全了行为 —— `drag=true`、`orientation=horizontal`、`on-scroll=true`、`direction=left`、`hover-pause=true`、`speed=50`（内部滚动速度 50）；卡片宽 `15.5rem`、`aspect-ratio: 248/330`。
- section 类名有 `cc-hs-hero`、`webgl_slider_wrap`；全页 6 个 `<video>`。

### 2. 动效手法（时长 / 缓动）

Webflow 的动效是**令牌化的**，全部走 CSS 变量，这是四站里最值得抄的一层：

- 过渡时长：`--transition-duration-1..7` = **150ms / 300ms / 450ms / 750ms / 1200ms / 1950ms / 3150ms**；`prefers-reduced-motion` 时全部置 0ms（不是删动画，是把时长归零，保留状态终值）。
- 缓动：`--transition-timing-inoutquad: cubic-bezier(0.455, 0.03, 0.515, 0.955)`、`inoutcubic: cubic-bezier(0.645, 0.045, 0.355, 1)`、`inoutquart: cubic-bezier(0.77, 0, 0.175, 1)`。
- 动画时长：`--animation-duration-1..4` = **0.3s / 0.45s / 0.75s / 1.2s**。
- 延迟阶梯：`--animation-delay-d0..d7` = **0s / 0.3s / 0.45s / 0.75s / 1.2s / 1.95s / 2.7s / 3.45s**。
- 滚动揭示：`[data-animation-css^='large']` → `animation-duration: var(--animation-duration-4)`（1.2s）+ `inoutquad`；`large-1` … `large-7` 依次挂 `d0` → `d6`，**错峰靠纯 CSS 属性选择器**，不需要 JS 逐个算延迟。
- `[data-animation-css^='small']` 额外加 `backface-visibility: hidden; transform: translateZ(0); will-change: transform, opacity; animation-fill-mode: both;`，关键帧 `scale`：`from { opacity: 0; transform: scale(1.015) } to { opacity: 1; transform: scale(1) }` —— 缩放幅度只有 1.5%。
- `[data-animation-css^='fade']` 默认 `animation: none !important`（淡入只留作兜底，默认关掉）。
- 卡片 hover：`[data-marquee-card]::before` 把 1px 描边外扩 `top/right/left: -0.5rem; bottom: -1.5rem`，`opacity 0→1` + `transform: scale(0.95)→1`，分别走 150ms 与 300ms 的 `inoutcubic`。

### 3. 配色与表面

- 黑：`--_color---neutral--black: #080808`（不是 `#000`）。主蓝：`--_color---primary--webflow-blue: #146ef5`。
- 灰阶完整 9 档：100 `#f0f0f0` / 200 `#d8d8d8` / 300 `#ababab` / 400 `#898989` / 500 `#757575` / 600 `#5a5a5a` / 700 `#363636` / 800 `#222` / 900 `#171717`。
- 辅助色：紫 `#7a3dff`、粉 `#ed52cb`；强调色另有 `#ff6b00` / `#00d722` / `#0055d4` / `#ee1d36` / `#3b89ff` / `#ffae13` / `#006acc`。
- 淡色底不写死 hex，用派生：`--colors--primary-accent-background: color-mix(in hsl, var(--colors--primary-accent) 92%, var(--colors--text) 8%)`，另一种场景 `color-mix(… 10%, transparent 90%)`。
- 表面：**细描边 + 近乎零阴影**。`border: 1px solid var(--colors--border)`（= gray-200 `#d8d8d8`）是主要分界手段。`box-shadow` 全表 13 处 `none`，只有卡片堆叠这种特殊场景才用多重投影（`0 9px 4px #0000001f, 0 17px 17px #0000001a, 0 38px 23px #0000000f, 0 67px 27px #00000005, 0 105px 30px #0000`），另外用 `inset 0 0 0 100px` 做遮罩。
- 圆角：卡片 `--_components---card--border-radius: .5rem`（8px），按钮/输入框 `.25rem`（4px）—— **卡片比控件圆**，这个反常识的分配让卡片显软、控件显硬。

### 4. 排版

- 字体族：自定义 `WF Visual Sans Variable`，等宽用 `Inconsolata`。
- 令牌（全 clamp 流体）：h1 `clamp(2.75rem, …, 5rem)`（44–80px）/ `line-height: 1.04` / `600` / `letter-spacing: -.01em`；h2 `clamp(2rem, 3.5rem)` lh 1.04 w600；h3 `clamp(1.75, 2.5rem)` lh 1.2；h4 `(1.375, 2rem)` lh 1.2；h5 `(1.25, 1.5rem)` lh 1.3；h6 `(1.125, 1.25rem)` lh 1.4；正文 `1rem / 1.6 / 400`；eyebrow `clamp(1, 1.25rem) / 1.4 / 500`；caption `.8rem / 1.2 / 550`。
- 行长直接做成工具类：`.u-max-40ch` / `50ch` / `60ch` / `80ch` / `20ch` / `30ch`，hero 副标题用 **40ch**。
- 注意标题行高：h1–h2 全是 1.04，几乎贴着字；但小字号 h5/h6 放到 1.3/1.4。

### 5. 对「先查」可抄的三条

1. **把行长做成 token/工具类**：先查副标题写的是 `max-w-[680px]`，按 15px 中文字宽算约 45 个汉字，偏宽。改成按 `ch` 或按固定汉字数（如 `max-w-[34em]`）限制，阅读更省力；文章/规则详情页尤其需要。
2. **卡片圆角大于控件圆角**：先查现在卡片 `rounded-xl`、输入框也 `rounded-xl`（都是同一档）。改成卡片 12px / 输入框 8px / 按钮 8px，让「容器软、控件硬」，层级一眼分清。
3. **滚动揭示用 CSS 属性选择器错峰**：先查靠 `Reveal :delay="0/90/180/270/360"` 手写延迟；改成像 Webflow 那样给容器 `data-stagger="1..7"` + 一段 CSS 挂 `nth` 延迟，页面里就不用逐块数延迟值，新增卡片自动错峰。

## 三、htmlpage.cn（https://htmlpage.cn/）

标题「在线网页编辑器 - 低代码拖拽式网页设计工具 | HTMLPAGE」。这一节最有价值的是**它用纯 Tailwind + 纯 CSS 做到了看起来有动效**，没有动画库。

### 1. 首屏结构

- 顶部 pill 徽章：`inline-flex px-4 py-1.5 rounded-full bg-green-500/10 border border-green-500/30 text-sm text-green-300`，内容「🚀 免费网页制作工具 / 拖拽式构建 · 响应式 · 多模板可选」——徽章里直接塞了两个卖点。
- h1 两行：`text-4xl md:text-6xl font-bold`，**第二行是渐变色字** `bg-clip-text bg-gradient-to-r from-blue-400 to-purple-400`。
- 副标题：`text-lg md:text-xl text-slate-300 mb-10`，正文里嵌若干 `<strong class="text-white">` 把关键词提亮 —— 用行内加粗做层级，不换字号。
- 双 CTA：「开始制作」/「查看功能全景」；下面一行小字「基础功能免费使用…」。
- 布局：`grid gap-12 lg:grid-cols-2 items-center`，容器 `max-w-7xl mx-auto px-4 pt-16 pb-20 md:pt-24 md:pb-32`（上下 padding 上下呼应，`pt-16→md:pt-24`、`pb-20→md:pb-32`）。

### 2. 动效手法（时长 / 缓动）

- **零 JS 动画库**，`@keyframes` 只有 `pulse` 和 `spin`，全靠 `transition` + Tailwind 的 `group-hover`：
  - `duration-300` 出现 20 次、`duration-500` 出现 3 次 —— **全站就两个时长档**。
  - `group-hover:w-full` × 18：下划线从左往右长满（宽度 0 → 100%）。
  - `hover:translate-x-1` × 7、`hover:scale-105` × 3、`hover:opacity-20` × 2。
  - 卡片 hover 光：绝对定位一层 `bg-gradient-to-r from-blue-400 to-indigo-400 opacity-0 group-hover:opacity-20 transition-opacity duration-300`，鼠标进来才浮出 20% 的渐变。
- hero 底纹做法（可整段照抄结构）：section 用 `bg-gradient-to-b from-slate-900 via-slate-950 to-slate-950`，上面叠一层绝对定位的**内联 SVG data-URI 网格**（40×40 pattern，6 条线，`stroke:#1a2338`、`opacity="0.4"`、`stroke-width="1"`），再套 `[mask-image:linear-gradient(180deg,rgba(15,23,42,.95),rgba(15,23,42,.4))]` —— 顶部浓、底部淡。**零图片请求，纯 CSS/inline SVG。**

### 3. 配色与表面

- 深色 slate 体系：`slate-900` / `slate-950` / `#0f172a` / `#020617` / `#1e293b`。
- 卡片面：`bg-slate-900/50`（半透明，让底纹透出来），描边 `border-slate-700/50`。
- section 之间用 `border-y border-indigo-500/15` 分隔 —— 用带色相的极淡描边做分区，而不是换底色或加阴影。
- 强调色：绿（徽章 `green-500`，10%/30% 两档透明度）、蓝→紫渐变（h1 第二行）、蓝→靛蓝渐变（hover 光）。

### 4. 排版

- 字体族：Tailwind 默认栈 `ui-sans-serif, system-ui, sans-serif…`；代码块 `ui-monospace, SFMono-Regular, Menlo…`。**没有自定义字体**。
- 层级靠字号 + 字重 + 颜色三件套，不靠字体族：`text-sm`×49、`text-lg`×22、`font-semibold`×49。
- 圆角高频：`rounded-xl`×40、`rounded-full`×34（药丸徽章、按钮）。

### 5. 对「先查」可抄的三条

1. **`group-hover:w-full` 下划线**：先查已有 `.link-underline`（scaleX 0→1），若还想更「平」的实现，可用 width 过渡版；两者效果接近，不必重复做。
2. **hover 才亮 20% 的渐变叠层**：先查入口卡 hover 现在只有边框变色 + `--shadow-hover`。可在卡片内加一层绝对定位 `opacity-0 → hover:opacity-20`、走 `--duration-base` 的 brand 渐变（`from brand-2 to brand`），成本一层 div、零图片。
3. **分隔用带色相的极淡描边，不换底色**：先查分区现在主要靠留白和 `border-line`；可在「第二层排队中」这类次级区块上加 `border-y` + brand 5–10% 透明度描边，比加深底色更轻。

## 五、可落地清单（10 条）

按「改动成本低 → 收益明显」排序，全部是增量，不动数据结构。

1. `.reveal` 起始透明度由 `0` 改 `0.001`，避免被判不渲染。
2. 新增 300–400ms「纯淡入」档，给卡片网格用，不与 620ms 位移档抢节奏。
3. 卡片圆角 12px、输入框/按钮 8px，容器软控件硬，一眼分层。
4. 副标题与正文行长改按 `em` 限宽（约 34em），别用固定 680px。
5. 卡片 hover 加一层 brand 渐变叠层，`opacity 0→0.2`，走 `--duration-base`。
6. 卡片 hover 的 1px 描边向外扩 4–8px，用 `::before` 做，不推挤布局。
7. 错峰改 CSS 属性选择器（`data-stagger`），不再逐块手写延迟。
8. 次级区块分隔改用 brand 5–10% 透明描边 + `border-y`，不加深底色。
9. 减少动效时把时长令牌统一置 0ms，而不是逐个删动画，保留终值。
10. h1 中文标题字距留 0，英文/数字标签类改 `-.01em ~ -.02em`。

> 说明：清单第 1、5、7、9 条对应 Framer / Webflow 的实证参数；第 2、3、4、6、8、10 条为四站共同模式在先查语境下的具体化。mobanwang 未取证，故未进入本清单。
