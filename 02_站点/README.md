# 先查 · 大学生的查询站（先做就业避坑）

一个纯静态的网页工具：把实习协议、三方协议、劳动合同粘贴进来，用内置规则库逐条比对，
把有风险的原句标红，并给出「为什么有风险 / 依据哪一条 / 建议怎么改」。

- 不联网、不注册、不上传：所有处理都在你的浏览器里完成。
- 没有构建步骤：不需要 Node、不需要 npm、不需要装任何东西。
- 一个文件夹拷走就能用：U 盘、网盘、微信传给自己都行。

---

## 一、怎么在自己电脑上打开

1. 找到文件夹 `02_站点`。
2. 双击里面的 `index.html`。
3. 默认会用浏览器打开首页，点「开始扫描合同」就能用。

推荐的浏览器：**Chrome / Edge**（Windows 自带 Edge 就够）。不要用 IE。

如果双击后打开的是记事本而不是浏览器：右键 `index.html` → 打开方式 → 选择 Chrome 或 Edge。

> 说明：整站按 `file://` 协议（也就是直接双击本地文件）设计过，页面用到的数据都内联在
> `js/data.js` 里，不依赖本地服务器。所以断网、拔网线、现场没有 Wi-Fi，都能正常演示。

## 三、答辩现场的三种兜底

现场网络、投影、浏览器都可能出问题，按这个顺序准备，任何一环失效都能接上：

| 顺序 | 方案 | 怎么准备 | 什么时候用 |
|---|---|---|---|
| 1 | **本地双击打开** | 把整个 `02_站点` 文件夹拷到答辩用的电脑（或 U 盘）上，提前双击确认能打开 | 默认方案，最稳，断网也能用 |
| 2 | **pages.dev 链接** | 提前把上面第四步的链接存进手机备忘录和浏览器书签 | 评委想在自己手机上试，或本地文件打不开 |
| 3 | **提前录屏** | 用系统自带录屏，完整走一遍「粘贴合同 → 扫描 → 看风险点 → 导出 .txt」，存成 mp4 放桌面 | 现场电脑卡住、浏览器版本太旧、时间被压缩 |

补充几条现场经验：

- 演示前**先把示例合同准备好**：扫描页有个「填入示例合同」按钮，点一下就有现成文本，不用现场打字。
- 浏览器提前打开到 `scan.html`，别从首页开始一层层点。
- 如果投影分辨率低，按 `Ctrl` + `+` 放大页面，布局是响应式的，放大不会错位。
- 别在现场填 AI Key、别现场联网调接口。AI 模式是「有则更好」，本地模式才是主线。

## 四、数据都在本地，怎么导出备份

站内所有个人数据都保存在**当前浏览器**的 localStorage 里，键名统一以 `xc.` 开头，包括：

- 收藏的案例（`xc.traps.favs`）
- 最近一次扫描的记录（`xc.scan.last`，只存脱敏后的前 3000 字）
- AI 设置（`xc.ai.baseUrl` / `xc.ai.key` / `xc.ai.model`）
- 自己填的考试日期（`xc.certs.dates`）

**导出**：打开「避坑库」页 → 页面底部「导出本地数据（.json）」，会下载一个
`先查-本地数据备份.json`，里面就是上面这些内容。

**导入**：同一位置点「导入备份」，选那个 json 文件，页面会覆盖同名数据并刷新。

**清空**：点「清空本地数据」，会二次确认，清完不可恢复。

> 注意：localStorage 是**按浏览器 + 按设备**隔离的。换电脑、换浏览器、用无痕窗口、
> 清理浏览器缓存，数据都会丢。重要内容请导出备份。
> 如果浏览器禁用了本地存储（部分无痕模式会），页面顶部会出现黄色提示条，
> 此时工具仍可正常扫描，只是关掉页面后记录不保留。

## 五、AI 模式：Key 怎么配，为什么默认不开

**怎么配：**

1. 打开「合同扫描」页，切到「AI 增强模式（可选）」。
2. 填三项：
   - **API Key**：你自己账号的 Key，形如 `sk-...`
   - **接口地址**：填到 `/v1` 即可，例如 `https://api.openai.com/v1`；
     程序会自动补 `/chat/completions`。用其他兼容 OpenAI 协议的服务商就填他们的地址。
   - **模型名**：例如 `gpt-4o-mini`，填你账号能用的模型。
3. 点「保存到本机」。Key 会以明文存进**当前浏览器**的 localStorage，键名 `xc.ai.key`。
4. 扫描时如果处于 AI 模式，程序会在本地规则结果之外，额外请求一次模型，做更细的解释。

**为什么默认不开：**

- **隐私**：AI 模式会把文本发出去。虽然扫描前已经做过脱敏（身份证、手机号、
  统一社会信用代码、银行卡号都替换成 ●●●●），但合同里仍可能包含公司名、岗位、
  薪资等商业信息。发不发、发给谁，应该由你本人决定，而不是默认替你决定。
- **稳定性**：断网、接口限流、Key 过期、余额不足都会失败。比赛现场网络不可控，
  本地模式永远不会失败，所以它是默认项。
- **成本**：调用是按量计费的，虽然单次很便宜，但没必要让每个用户先为它买单。
- **可解释性**：风险清单的每一条都对应规则库里的具体规则和法条条号，能溯源；
  大模型生成的内容只作为补充解释，不写进风险清单主体。

**安全提醒：**

- **不要在公共电脑、网吧、别人的笔记本上填自己的 Key。**
- 不用了就在同一位置点「删除已保存的 Key」。
- 页面里 Key 输入框是密码类型，但保存到 localStorage 后是明文，
  浏览器开发者工具能看到——这是纯静态站点绕不开的限制，请知悉。

**失败会怎样：**没有 Key、Key 错误、接口 404/401、网络超时、返回为空——
任何一步失败，页面都会提示「已切回本地模式」，并继续使用本地规则的结果，
不会卡住，也不会白屏。

## 附：文件结构与自查

```
02_站点/
  index.html          首页：定位 + 三个入口
  scan.html           合同风险扫描（核心页）
  traps.html          避坑案例库（搜索 / 筛选 / 收藏）
  certs.html          考证日历（表格 + 倒计时 + 筛选）
  about.html          关于我们
  css/style.css       全站样式
  js/storage.js       localStorage 封装（xc.* 命名空间）
  js/traps.js         风险规则库（63 条）
  js/app.js           公共交互（导航 / 导出导入 / 收藏）
  js/scan.js          扫描与脱敏逻辑
  js/data.js          由 data/*.json 生成的内联数据（file:// 兜底）
  data/traps.json     案例数据（12 条，源文件）
  data/certs.json     证书数据（6 条，源文件）
  check.js            静态自查脚本
  README.md           本文件
```

**改数据之后要重新生成 `js/data.js`**，否则页面读到的还是旧数据：

```
node check.js --gen      # 从 data/*.json 重新生成 js/data.js
node check.js            # 检查所有页面引用的文件是否存在、编码是否正常
```

（只在改数据时需要跑；平时双击 index.html 直接用，不需要 Node。）
